# Documentation

The pipeline that keeps WBA's Disclosure Library current: company pages watched every night, reports harvested and read, gaps measured per company, and a quality log that records every way it fails.

**New here, or lost? Read [guide.md](guide.md) first**: the owner's guide in plain words (how a document travels, the daily routine, the fields you edit, how types and years are decided, Pipeline QA, what to read before merging).

Field-level documentation lives in Airtable itself: every field in the Disclosure Library and the Pipeline QA base carries a description, kept current with the code. [fields.md](fields.md) lays them out on one page; regenerate it with `field_docs.py` after changing descriptions.
