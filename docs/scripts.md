# Scripts and workflows

Every script is a dry run unless given `--commit` (scheduled and chained runs pass it). Times are UTC. "After X" means the workflow starts when workflow X completes successfully.

Known silent failures per script were inventoried on 21 Oct 2026 (commit aa278c6); the full table is in the design document linked from [quality.md](quality.md). The ones still open are tracked as rows in the Pipeline QA base.

## Manual, one-off and diagnostic
`field_docs.py` (writes `docs/fields.md` from the Airtable schema of both bases; read-only, `--from-json` or the meta API), `active_search.py` (homepage crawl for new pages), `link_documents.py` (one-off source_page links), `fetch_logos.py`, `unmonitor_shared.py` (switch off pages shared by 3+ companies), `diagnose_attach.py`, `diagnose_blocked.py` (read-only diagnoses; diagnose_blocked also tallies robots.txt for the refused pages and the refused documents, `blocked_diagnosis.csv` and `blocked_documents_robots.csv`), `search_check.py` (Search check workflow, manual and on pull requests touching the search functions: read-only timings of sample searches in the evidence database, recorded in Pipeline QA runs), `site/index.html` (Search page workflow, on push to main: publishes the evidence search page on GitHub Pages with the Supabase address and publishable key filled in), `supabase_check.py` (Supabase check workflow, manual and on pull requests: read-only test that the evidence database answers with the SUPABASE_URL, SUPABASE_SERVICE_KEY and SUPABASE_DB_URL secrets), `ids.py` (normalize, doc_key, doc_id, link_id).
